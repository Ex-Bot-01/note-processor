# ADR 0002 — One machine, one user, loopback HTTP with a token

**Status:** accepted. **Asked:** Whether np is a service with accounts or a program on your own box.
**Recorded here:** 2026-11-20, moved verbatim from `todo.md`'s "Locked decisions" list; a ruling date quoted below is as it

## Decision

Single machine, single user. Loopback HTTP + token in config (port 8765) — no cloud, no accounts.
