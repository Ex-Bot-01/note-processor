# ADR 0007 — Derived data lives in the database and `INDEX.md`, with no importance filter

**Status:** accepted. **Asked:** Where derived data goes, and whether np may decide which notes matter.
**Recorded here:** 2026-11-20, moved verbatim from `todo.md`'s "Locked decisions" list; a ruling date quoted below is as it
was recorded there.

## Decision

Derived data lives in the DB and `INDEX.md`, one catalog entry per note, **no importance filter**.
